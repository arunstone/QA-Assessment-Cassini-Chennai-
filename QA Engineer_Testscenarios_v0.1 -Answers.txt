Title:	Validate API accepts valid UniqCltID

Endpoint:	POST /api/v1/trade

Payload:	{"Client":"Bob Smith","Company":"ABC","UniqCltID":"JPM000023789","Product":"ISX","Quantity":100,"Price":17}

Expected Result:	201 Created

Validations	
 Status = 201	
 UniqCltID matches regex ^[A-Z]{3}[0-9]{9}$	
 Response echoes UniqCltID	
 DB contains same UniqCltID after commit	
 
 Code :
import re
def test_valid_uniqcltid(session, base_urls):
    payload = {
        "Client": "Bob Smith",
        "Company": "ABC",
        "UniqCltID": "JPM000023789",
        "Product": "ISX",
        "Quantity": 100,
        "Price": 17
    }
    response = session.post(f"{base_urls['gorest']}/trades", json=payload)
    assert response.status_code == 201
    assert re.match(r"^[A-Z]{3}[0-9]{9}$", payload["UniqCltID"])

Field Validation Rule | 3 letters + 9 digits regex | Pre-validate in automation via regex before API call 

System Integration | Field must flow across multiple systems | Build chained tests verifying propagation

Legacy Compatibility | Older messages missing ID  | Maintain dual-schema testing                      

Environment Sync | Different systems might not update simultaneously | Use feature flags / version headers in API
